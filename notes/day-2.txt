directive:
----------------------
a. structural directive: they manipulate DOM
ex: *ngFor, *ngIf, *ngSwitch etc.

b. attribute directive: they extend the behavior of the element
ex: ngModel, ngForm, ....

c. component directive: components, a directive with a template or view


how to pass data from one to another component:
------------------------------------------------------
a. passing data between a parent and nested component when the components are shallowly nested
	@Input() -> Decorator that marks a class field as an input property and supplies configuration metadata. The input property is bound to a DOM property in the template. During change detection, Angular automatically updates the data property with the DOM property's value.

	@Output() -> Use in components with the @Output directive to emit custom events synchronously or asynchronously, and register handlers for those events by subscribing to an instance.
b. passing data between a parent and nested component when the components are deeply nested



Pipes:
-------------------

@Pipe({
	name:'uppercase'
})
export class UppercasePipe{
	transform(value:string, ...args:any[]):string{
		return value.toLocaleUpperCase()
	}
}


{{name|uppercase}} => new UppercasePipe().transform(name)


@Pipe({
	name:'currency'
})
export class CurrencyPipe implements PipeTransform{
	transform(value:any, ...args:any[]):any{
		return value.toLocaleUpperCase()
	}
}

{{p.salary|currency:'INR':'':''}} => new CurrencyPipe().transform(salary,'INR')

Dependency Injection of the service:
------------------------------------------

A. when token name is same as that of the service class name

token: CalculationService

provider:Provider

{
	provide: CalculationService
	useClass: CalculationService
}

consuming the service:

1. using constructor
----------------------
export class Calculator{
	private calcSvc:CalculationService;

	constructor(svc:CalculationService){
		this.calcSvc = svc
	}
}

2. using inject() method
------------------------
export class Calculator{
	private calcSvc:CalculationService = inject(CalculationService);
}


B. When token is a string value
----------------------------------------
token:'TOKEN'

provider:
{
	provide: ‘TOKEN’
	useClass: CalculationService
}

1. using constructor
---------------------------
export class Calculator{
	private calcSvc:CalculationService;

	constructor(@Inject('TOKEN') svc:CalculationService){
		this.calcSvc = svc
	}
}

2. using inject() method
-------------------------------
//not possible to use inject() method string type token
export class Calculator{
	private calcSvc:CalculationService = inject(CalculationService);
}

C. when token is an InjectionToken type object
-------------------------------------------------
token: 
export const TOKEN = new InjectionToken<CalculationService>(‘TOKEN’)

provider:
{
	provide: TOKEN
	useClass: CalculationService
}

1. using constructor
------------------------------
export class Calculator{
	private calcSvc:CalculationService;

	constructor(@Inject(TOKEN) svc:CalculationService){
		this.calcSvc = svc
	}
}

2. using inject() method
-------------------------------
export class Calculator{
	private calcSvc:CalculationService = inject<CalculationService>(TOKEN);
}
